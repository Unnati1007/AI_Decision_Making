# Decision Framework: Interview Preparation & Evaluation Rubrics

## 📌 Executive Summary
Tech interviews evaluate candidate competence across Coding/DSA, System Architecture, and Behavioral fit. Structuring responses using standardized evaluation rubrics significantly boosts offer conversion rates.

## 🎯 Behavioral Interviewing: The STAR Method
When answering situational questions ("Tell me about a time you had a conflict", "Describe a complex bug you solved"):
- **S - Situation**: Set the context (Company, project scope, constraints) in 2–3 sentences.
- **T - Task**: Define your specific responsibility or problem statement.
- **A - Action (60% of time)**: Detail the precise actions **you** took (technical choices, trade-off evaluations, stakeholder alignment).
- **R - Result**: Quantify the impact (e.g., *"Reduced latency by 45%", "Saved 12 hours of manual QA per sprint"*).

## 🏗️ System Design Interview Framework (45-Minute Loop)
1. **Scope Clarification & Functional Requirements (5 Mins)**: Clarify DAU/MAU, read/write ratios, peak throughput (QPS), and latency targets (p99).
2. **High-Level Architecture & API Specs (15 Mins)**: Draw API endpoints, database schemas, load balancers, caching layers, and database choice (SQL vs NoSQL).
3. **Deep Dive & Bottleneck Resolution (20 Mins)**: Address database sharding, replication lags, cache invalidation, rate limiting, and failure modes.
4. **Trade-offs & Wrap-Up (5 Mins)**: Discuss CAP theorem choices, cost optimization, and alternative architectural decisions.

## ⚖️ HR & Bar Raiser Round Evaluation Rubric
| Evaluation Metric | Green Flag (Strong Hire) | Red Flag (No Hire) |
| :--- | :--- | :--- |
| **Ownership** | Admits past mistakes, highlights learning, takes accountability. | Blames teammates, management, or legacy code. |
| **Technical Depth** | Explains trade-offs & underlying mechanics (e.g., why PostgreSQL over MongoDB). | Uses buzzwords without understanding internal architecture. |
| **Communication** | Structured, concise, listens actively before answering. | Rambles, interrupts interviewer, defensive under questioning. |
| **Salary Alignment** | Researched market benchmarks, delays anchor until offer phase. | Demands fixed number upfront without knowing role scope. |
